# Стереометрия әлемі

Куб, конус, цилиндр және сфера бойынша интерактивті оқу сайты.

**Сайт:** https://darhanor07-art.github.io/-/

Сайт бір ғана файлдан тұрады (`index.html`), серверді қажет етпейді. Компьютер мен телефон браузерінде ашылады.

## GitHub Pages-ті қосу (бір рет)

1. Репозиторийде **Settings → Pages** бетін ашыңыз.
2. **Source:** Deploy from a branch.
3. **Branch:** `main`, қапшық `/ (root)`, сосын **Save**.
4. 1–2 минуттан кейін сайт жоғарыдағы мекенжайда ашылады.

Репозиторий ашық (public) болуы керек.
